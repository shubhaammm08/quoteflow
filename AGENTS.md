# Antigravity Agents Configuration

This workspace is configured with specialized skills and plugins to assist with development.

## Plugins

* **Vercel Plugin (`vercel-plugin`)**: Use this plugin for managing Vercel deployments, inspecting environments, and handling related web app workflows.
* **Ponytail Plugin (`ponytail`)**: Use the Ponytail plugin and its associated skills (`ponytail`, `ponytail-audit`, `ponytail-review`, etc.) whenever you need the simplest, most minimal, "lazy" solution to a coding problem. Trigger this mode with keywords like "ponytail", "simplest solution", "do less", or "be lazy".

## Skills

* **Taste Skill (`Leonxlnx/taste-skill`)**: A comprehensive suite of 13 design-focused skills for premium frontend development.
  * Use `design-taste-frontend` or `design-taste-frontend-v1` for high-end, anti-slop UI design and layout implementation.
  * Use `stitch-design-taste` when generating or applying Google Stitch design systems.
  * Use `image-to-code` for highly accurate implementations of design mocks.
  * Use aesthetic-specific skills like `minimalist-ui`, `industrial-brutalist-ui`, `brandkit`, or `high-end-visual-design` when specific visual directions are requested.
  * Use `imagegen-frontend-web` or `imagegen-frontend-mobile` for generating premium design references before coding.
  * Use `full-output-enforcement` when generating large, unabridged files.

## MCP Servers

* **Stitch MCP**: Use the local Stitch MCP server to create, edit, and manage Google Stitch projects and screens directly from the workspace.
